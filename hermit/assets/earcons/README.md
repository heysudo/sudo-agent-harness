# Earcons

Borrowed from the `heysudo/b2-34` project (`assets/earcons/`, generated by
`scripts/make_earcons.py` — mono s16le 16 kHz, hermit's native format, so they
play with zero conversion).

| file | played when |
|---|---|
| `trigger_ack.wav` | wake word fires — instant "heard you" |
| `thinking.wav` | end of speech — "stopped listening, working on it" |
| `listening.wav` | (unwired spare) |
| `ready.wav` | (unwired spare — boot complete) |
| `session_close.wav` | (unwired spare) |
| `attention.wav` | (unwired spare — proactive speech) |

Loaded from `/opt/hermit/assets/earcons` (override: `HERMIT_ASSET_DIR`).
Regenerate with `scripts/make_earcons.py`.
