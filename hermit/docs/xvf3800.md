# XVF3800 mic array: what hermit assumes and how to tune it

The reference mic board is the Seeed reSpeaker Flex (XMOS XVF3800, linear
4-mic, USB). It is not a dumb microphone: on-chip DSP does AEC, beamforming,
noise suppression, and AGC before hermit ever sees a sample, and every stage
is tunable over USB vendor control transfers. `tools/xvf3800/` holds the
control tool; this page holds the hard-won facts.

## Setup (once per device)

```bash
sudo bash tools/xvf3800/setup.sh
```

Installs `xvf` to /usr/local/bin (pyusb, no vendor SDK), adds a udev rule so
the audio group can drive the chip, raises the AGC target, and persists the
tuning to chip flash.

## The one tuning that matters

Factory firmware ships `PP_AGCDESIREDLEVEL = 0.0045` (~-47 dBFS): the AGC
deliberately normalizes speech to whisper level. Wake models and cloud STT
VADs are trained on normal-level audio, so an untuned board produces the
"device cannot hear" failure class: wake scores near zero, empty
transcripts, VAD that never opens.

`setup.sh` raises the target to `0.036` (~-29 dBFS), on-chip, ahead of the
noise suppressor - strictly better than multiplying samples in software
after the fact. With it applied, `wake.gain` and `stt.sarvam_gain` stay at
`1.0` in hermit.toml. Without it (stock board), set both to `8.0` and
expect somewhat worse SNR.

## Reading and writing parameters

```bash
xvf                              # list supported parameters
xvf VERSION                      # firmware (reference board: 2.0.7)
xvf PP_AGCGAIN                   # current AGC gain
xvf AEC_AECCONVERGED             # 1 = echo canceller locked
xvf PP_AGCDESIREDLEVEL --values 0.036   # write
xvf SAVE_CONFIGURATION --values 1       # persist current state to flash
```

## Direction of arrival (DoA)

`xvf DOA_VALUE` returns `[angle_deg, activity_flag]` at ~10 Hz. Two facts
to design around, both measured on hardware:

- DoA runs PRE-AEC: it tracks the loudest source in the room *including
  the device speaker*. With music playing it parks on the speaker angle;
  a talker must out-shout the residual to move it.
- The linear array resolves a 180-degree half-plane. On the reference
  device the speaker reads ~353 deg and quiet-room ambient ~87 deg.

Planned use (not yet wired into the daemon): gate the follow-up listen
window on "speech from roughly the wake direction, not the speaker
direction", and demand a higher wake score when DoA sits on the speaker
while music plays.

## Sharp edges

- Channel 0 is the processed voice beam; channel 1 is raw. Capture is
  clock-slaved to playback: arecord returns EIO unless something is
  playing (hermit keeps a silence stream open for this).
- The Flex firmware line is its own versioning (v1.0.x images named
  `respeaker_flex_usb_l*` for linear, `c*` for circular). Do NOT flash
  images for the circular reSpeaker XVF3800: mic geometry is baked into
  the beamformer. Firmware >= 2.1.0 advice found for other XVF3800
  products does not map onto this board.
- `SAVE_CONFIGURATION` persists everything, including experiments you
  forgot you made. `CLEAR_CONFIGURATION --values 1` returns to factory.
- The parameter map in xvf.py is the subset relevant to hermit, ported
  from pollen-robotics/reachy_mini (Apache-2.0) with Seeed Flex USB IDs
  and the DOA_VALUE register from Seeed reSpeaker_Flex python_control.
